dYT

Fast, reliable YouTube downloads. Version @VERSION@.

Install on Linux Android APK Source
  • Many connections at once, so downloads run as fast as your line allows
  • Clips fetch only the part you pick and cut on the exact timestamp
  • Video, audio or both, at the quality you choose, or the raw streams
  • Recovers from dropped connections and expired links on its own

Linux (Flatpak)

flatpak install --user https://dixonsolutions.github.io/dYT/dyt.flatpakref

Or add the repository once and install from it; flatpak update keeps dYT current:

flatpak remote-add --user --if-not-exists dyt https://dixonsolutions.github.io/dYT/dyt.flatpakrepo
flatpak install --user dyt io.github.dixonsolutions.dyt

Android

Download the APK from the latest release and open it. Then share any YouTube link to dYT, or open it with dYT.
